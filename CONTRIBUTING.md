# Contributing to poutre2
Thanks to be there :)

# Submitting patches

Patches should be submitted through Github PR. 
Poutre2 use [clang-format](https://clang.llvm.org/docs/ClangFormat.html) to keep
the coding style consistent, a ``.clang-format`` file is shipped within the
source.

# Extending the API

You could add new functions/objects as long as it has been discussed either in an
Issue or a PR. 
The constraint is to add testing for new functions/objects, and make
sure they work on all supported systems.
You could also add benchmarking suites

# Licensing

Poutre2 use a shared copyright model that enables all contributors to maintain the
copyright on their contributions. Stated otherwise, there's no copyright
assignment.
